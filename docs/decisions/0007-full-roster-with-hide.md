# 0007: 名簿は見られる人全員を載せ、載せたくない人はコマンドで外れる

- 日付: 2026-11-10
- 状態: 採用中（方針を変えたら、このファイルは書き換えず、新しい ADR を作ってここを「廃止（NNNN で置き換え）」にする）
- 関連: [0005](0005-mentions-and-roster-command.md) 判断2（写しが流れた人だけ。この ADR で置き換え）

## 判断1: 同期チャンネルを見られる人全員を載せる（発案者）

**決めたこと**：`/nepsync-members` に、どちらかのサーバーでそのチャンネルを見られる人を全員載せる。一度も発言していない人も載る。bot と、Neplector から外れた人は載らない。（2026-11-18 追記：[0014](0014-easier-cross-server-mentions.md) 判断1 で、出すのは相手のサーバーにだけいる人に絞った）

**検討した選択肢**：

- 案A（採用）：全員を載せて、外れたい人はコマンドで外れる。まだ発言していない人にも呼びかけられる
- 案B（却下、0005 判断2）：写しが流れた人だけ。新しく知られる名前は無いが、初めての人に呼びかけられない

**引き換え**：一度も発言していない人の名前・ID・アイコンが、相手のサーバーの人に見える。Neplector の告知は名簿の公開に触れていないので、両方のサーバーに、名簿と `/nepsync-hide` のことを知らせる（発案者が投稿する）。

## 判断2: `/nepsync-hide`・`/nepsync-show` で、自分を載せない・載せるに戻す（発案者）

**決めたこと**：

- 外れるのは名簿だけ。発言の同期、メンション、リアクションの名前の表示は変わらない
- どちらのサーバーで実行しても、両方の名簿から外れる
- 返事は実行した人にだけ見せる
- 保存するのは ID だけ（`roster_hidden`）。Neplector から外れた人は、この設定も消す（外れた人の ID を手元に残さない。戻ってきたら、名簿にまた載る）

**検討した選択肢**：

- 案A（採用）：載せない・戻す、の2つのコマンド。何が起きるかが名前で分かる
- 案B（却下）：1つのコマンドで切り替える。今どちらの状態かが分かりにくい

## 用語メモ

- オプトアウト：自分から「対象から外して」と申し出ること
