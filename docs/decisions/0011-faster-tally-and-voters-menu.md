# 0011: 投票の合計を早く書き換え、投票した人を右クリックで見られるようにする

- 日付: 2026-11-10
- 状態: 採用中（方針を変えたら、このファイルは書き換えず、新しい ADR を作ってここを「廃止（NNNN で置き換え）」にする）
- 関連: [0004](0004-reactions-and-polls.md) 判断4（合計は1分に1回まで。この ADR で置き換え）・判断6（リアクションした人のメニュー。同じ形にする）

## 判断1: 合計の発言は、10秒に1回まで書き換える（発案者）

**決めたこと**：「📊 投票の合計」の発言を書き換える間隔を、1つの投票につき最大で1分に1回から、10秒に1回にする。書き換え待ちの投票があるあいだは、Neplector の変更を待つ時間（ふだんは最大25秒）を、書き換えてよい時刻までに縮める。票が入ってから合計が変わるまでは、長くて10秒ほど（Neplector に記録が届くまでの時間を足す）。

**検討した選択肢**：

- 案A（採用）：10秒に1回。Discord の書き込みの回数制限（短い時間に書きすぎると待たされる決まり）に、かかりにくい間隔
- 案B（却下）：票のたびにすぐ書き換える。多くの人が一度に投票すると書き込みが続き、ほかの同期が待たされる
- 案C（却下）：今のまま1分に1回。発案者が「リアルタイムに近づけたい」

**変わらないこと**：合計の発言には票の数だけを書き、誰が投票したかは書かない（0004 判断4）。

## 判断2: 「投票した人」を、発言の右クリックのメニューで、押した人にだけ見せる（発案者）

**決めたこと**：発言の右クリックの「アプリ」に「投票した人」を足す。両方のサーバーの票を、選択肢ごとにまとめ、その下にサーバーごとの名前（アイコンの絵文字つき）を並べる。答えは押した人にだけ見え、誰も呼ばない。投票と、その写しと、両方の「投票の合計」の発言のどれを右クリックしても使える。

- 人数は合計の発言と同じ数え方（同じ人が両方で同じ選択肢に投票しても1人）
- 外れた人の票は Neplector に無いので出ない。外れた人が作った投票は「表示できません」
- 名前は Neplector の名簿から。名簿にまだ無い人は「メンバー」

**選んだ理由**：Discord の投票は、同じサーバーの人なら誰でも「誰がどれに投票したか」を見られる。同期した投票は両方のサーバーの人で1つの投票なので、見られる範囲を相手のサーバーの人まで広げても、Discord の投票の見え方と同じになる。「リアクションした人」（0004 判断6）と同じ形にした。

**検討した選択肢**：

- 案A（採用）：右クリックのメニューで、押した人にだけ見せる
- 案B（却下）：合計の発言に名前も書く。全員に出続け、人数が多いと 2000 文字に収まらない
- 案C（却下）：「リアクションした人」のメニューに一緒に出す。投票ではない発言では要らない段が増え、分かりにくい

**引き換え**：発言の右クリックのメニューは、1つのサーバーに5つまでという Discord の決まりがある。これで4つ（リアクションした人・投票した人・相手のサーバーにも出す・相手のサーバーから下げる）になり、足せるのはあと1つ。

## 用語メモ

- 右クリックのメニュー（コンテキストメニュー）：発言を右クリック（スマホは長押し）して「アプリ」から選ぶ、bot のコマンド
