# 0014: 相手のサーバーの人を呼びやすくする（名簿の作り直しと、返信での通知）

- 日付: 2026-11-18
- 状態: 下書き（作って、発案者がスマホとPCで試してから採用にする。2026-11-18：判断5 のコピーの形は試して決めた。判断4 の選び足しを直して、もう一度試す）
- 関連: [0005](0005-mentions-and-roster-command.md) 判断1・判断2a（この ADR で名簿の見せ方を置き換える）、[0007](0007-full-roster-with-hide.md)（載せる人・外れる人は変えない）、[0004](0004-reactions-and-polls.md) 判断8（アイコンの絵文字）

## きっかけ

発案者の声（2026-11-18）：`/nepsync-members` は、打つと全員が縦に並んで出るので、呼びたい人を探すのがだるい。アイコンが小さい。スマホでは、埋め込みの中のコードブロックだけをコピーできない。

前提：bot は、人の入力欄に文字を入れられない。クリップボードに写すボタンも作れない（Discord の決まり）。相手のサーバーの人は、Discord の入力候補に出ない。

## 判断1: 名簿に出すのは、相手のサーバーにだけいる人（発案者）

自分のサーバーにいる人（両方にいる人も）は、Discord の入力候補で呼べるので出さない。載せる条件（同期チャンネルを見られる・bot でない・`/nepsync-hide` していない）は 0007 のまま。

## 判断2: 名簿は、アイコンと名前を格子に並べた1枚の画像にする（発案者・Claude の案）

- 1ページ25人（横5×縦5）。大きめの丸いアイコンの下に、番号と名前。印：★（よく呼ぶ人）・🕘（最近選んだ）・💬（このチャンネルで最近発言した）
- 画像の下に、呼ぶ人を選ぶメニュー（最大25人。番号・名前・アイコンの絵文字）。25人を超えたら「前へ」「次へ」
- 画像は Pillow で作る。日本語の字体が要る（コンテナには `fonts-noto-cjk` を入れる）。アイコンは Discord の CDN から取り、画像を作るあいだだけ手元に置く
- 却下：埋め込みを縦に並べる（今の形。アイコンが小さい）、Discord の画像の並び（名前をアイコンの下に書けない）

## 判断3: 並べる順は ★ → 最近選んだ人 → このチャンネルで最近発言した人 → そのほかを名前順（発案者。案 B・C）

- ★ は、人を選んだ画面の「★ に入れる／外す」で、自分で決める
- 「最近選んだ人」は、名簿やメニューで選んだ相手を、1人につき新しいほうから 8 人まで残す
- 「最近発言した人」は、今ある写しの対応表（写しの ID と書いた人の ID）から出す。新しく保存しない
- **新しく保存するもの**：★ と最近選んだ人の、ID の組と時刻だけ（`roster_stars`・`roster_picks`）。発言の中身は残さない。Neplector から外れた人は、選んだ側でも選ばれた側でも消す（0007 判断2 の `roster_hidden` と同じ扱い）

## 判断4: 名前で探せる・何人かをまとめて選べる（発案者。案 E・F）

- `/nepsync-members 名前:`。打ち始めると候補が出る（最大25人）。候補を選ぶと、その人の「呼ぶ」画面がすぐ出る。候補を選ばずに送ると、当たる人の格子を出す
- 探し方はゆるくする：全角と半角、大文字と小文字、ひらがなとカタカナ、空白の違いを気にしない。前から当たる人を先に出す
- 格子の下のメニューで選ぶと、新しい返事は出さず、**名簿の発言の本文を、選んだ人の `<@ID>` の並びに書き換える**（発案者。返事が下に溜まっていくのを避ける）。あとから選び足せる。ページを送っても残る。最大10人。「選び直す」で空にする。1人だけのときは ★ のボタンも出す
- 選んでいる人は、名簿の発言の本文から読み取る（手元に覚えない。動かし直す前に出した名簿でも効く）

## 判断5: 呼ぶための文字は、本文に `<@ID>` だけを置く。長押しの「テキストをコピー」で写す（発案者が試して決めた）

- 名簿の発言でも「呼ぶ」画面でも、本文は選んだ人の `<@ID>` だけにする。長押しの「テキストをコピー」は本文だけを写すので、`<@ID>` がそのまま写る（スマホ）
- 本文の下の枠（埋め込み）には、同じ `<@ID>` をコードブロックで置く（PC。本文の `<@ID>` は PC では名前の印になって、選んでも写せない）。bot からは PC かスマホかが分からないので、両方を1つの返事に置く（発案者。2026-11-19）
- 説明の文は置かない（場所を取るので。発案者。2026-11-19）。誰も選んでいないあいだは、枠も出さない
- 2026-11-18 に、発案者がスマホで、本文の長押しで写せることを確かめた。同時に試した「コピー用の欄を開く」（`<@ID>` の入った入力欄の小窓）は、要らないのでやめた
- **入力欄に自動で入れることはできない**：bot は、人の入力欄に文字を入れられない（Discord の決まり）。案3（bot が代わりに投稿する）は、自分で編集・削除できず、Neplector の記録も bot の発言になるので、とらない

## 判断6: 写しの長押しのメニューに「この人を呼ぶ」を足す（発案者。案 D）

写しを長押し（PC は右クリック）→「アプリ」→「この人を呼ぶ」で、その写しを書いた人の「呼ぶ」画面が出る。写しでない発言では「相手のサーバーから来た写しにだけ使えます」。`/nepsync-hide` した人でも出す（名前はもう写しで見えている。0007 判断2 の「外れるのは名簿だけ」）。発言のメニューは1つのサーバーに5つまでで、これで5つになる。

## 判断7: 写しに返信すると、相手のサーバーで元の人に通知する（発案者。案 A）

- 写しに返信した発言の写しでは、引用の行の名前を `<@ID>` にして、その人に通知する
- Discord の返信の「@ オン/オフ」は、写し（Webhook の発言）への返信では読み取れないので、いつも通知する
- 自分の発言の写しに自分で返信したときは通知しない。編集では通知しない（0005 判断1 と同じ）

## 引き換え

- 名簿を開くたびにアイコンを最大25個取りに行くので、表示まで数秒かかる。同じページを開き直すときは、少しのあいだ手元に置いたものを使う
- コンテナが大きくなる（日本語の字体）
- 発言のメニューが上限の5つになる。次に足すときは、どれかをやめる

## 用語メモ

- Webhook：bot が、人の名前とアイコンで代わりに投稿する仕組み。写しはこれで出している
- 入力候補（オートコンプリート）：スラッシュコマンドの欄に打ち始めると、選べる候補が出る仕組み
