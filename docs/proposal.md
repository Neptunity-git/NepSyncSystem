# 企画書：NepSyncSystem

## 目的・コンセプト

同じコミュニティの2つの Discord サーバー（拠点）のあいだで、決めたカテゴリを、**中のチャンネルの構造ごと双方向に同期する**サービス。
どちらの拠点の人も、同じ名前のチャンネルで1つの会話をしているように話せるようにする。

データは Neplector の API（読むだけ）から受け取り、投稿は Webhook、チャンネルの操作は同期専用の bot で行う。
Neplector 側の位置づけは [Neplector ADR 0035](../../Neplector/docs/decisions/0035-one-community-across-servers-and-sync.md)（同期は Neplector に入れず、その上のサービスとして作る）。

## 対象ユーザー・利用シーン

- 使う人：両方のサーバーのメンバー。特別な操作は要らず、ふだんどおり話す
- 動かす人：運営者（発案者）。最初の設定と、知らせを受けたときの対応をする

例：拠点Aの「Nep共同企画」カテゴリに `議事録` チャンネルを作ると、拠点Bにも同じものができる。どちらかで発言すると、もう一方に発言者の名前とアイコンで届く。

## スコープ（やること / やらないこと）

**最初の版でやること**

- 発言：投稿・編集・削除、名前とアイコン、画像と動画、引用形式の返信、スレッド、フォーラムの投稿とタグ
- 構造：チャンネルの作成・削除・名前、カテゴリ名、トピック、並び順、低速モード、年齢制限、フォーラムのタグ
- 外れた人（`/neplector optout`）の発言の写しを消す
- 止まっていた間の発言を後で流し、遅れた印を付ける

**そのあと足したもの**

- リアクション（人数は同じにならない。[ADR 0004](decisions/0004-reactions-and-polls.md)）
- 投票（票はサーバー間で統合できないので、合計を別の発言に書く。ADR 0004）

**やらないこと**

- チャンネルの権限の同期（見える範囲がサーバーをまたいで変わり、会話が意図せず公開されるおそれがある）
- カテゴリ自体の自動作成（[ADR 0001](decisions/0001-sync-scope-and-bot-permissions.md) 判断4）
- テキストとフォーラム以外のチャンネル（ボイス、アナウンス、メディア）
- 同期を始める前の発言を流すこと（Neplector ADR 0035 判断6）
